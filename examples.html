Examples

Runnable companions to the book.

Every pattern chapter has an example behind it. Each example is a self-contained Python project in one uv workspace, with a pytest suite, pytest-mock where a collaborator needs substitution, and no containers. Read the matching chapter for context, then run the example from its directory with the same local uv and Python 3.14 toolchain the prerequisites chapter installs.

Runnable examples

Each example makes a single pattern or idiom concrete and runnable with one command. Every card links to the example's page on this site (a rendering of the README with cross-references), and each page links to the source on GitHub. Each example also stands alone and builds without the book.

Building every example

Clone the repo and run every example in one pass with the pinned local toolchain (uv and Python 3.14; see the prerequisites chapter and scripts/check-prereqs.sh). 

git clone https://github.com/{{ site.github_username }}/{{ site.github_repo }}.git
cd {{ site.github_repo }}
uv sync --locked --all-packages
./scripts/verify.sh

After the one-time uv sync --locked --all-packages at the root, every example also runs from its own directory with uv run pytest.
