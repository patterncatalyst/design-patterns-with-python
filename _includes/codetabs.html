{%- comment -%} Multi-language code tabs. Emits an empty marker; assets/js/codetabs.js absorbs the next N fenced code blocks (N = number of pipe-separated labels) into an accessible tab group. Because the code blocks stay ordinary Markdown fences, Rouge still highlights them at build time: no plugin required. Usage (place the bare include, then one fenced block per label, IN THIS ORDER). Do NOT wrap the include in raw tags, which stops Liquid running it: {% include codetabs.html langs="Class hierarchy|Idiomatic" %} ```python # Class hierarchy ``` ```python # Idiomatic ``` The default pair shows the class hierarchy the 1994 catalogue draws next to the form Python 3.14 supports directly (a callable, a dataclass, a protocol), so the two read side by side. Both tabs are Python. Other pairs of Python idioms use their own labels, for example "Before|After" or "Protocol|Callable". Selecting a tab syncs every group on the page and is remembered across pages. {%- endcomment -%}
