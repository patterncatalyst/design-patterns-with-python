Because the code blocks stay ordinary Markdown fences, Rouge still highlights them at build time: no plugin required. Usage (place the bare include, then one fenced block per label, IN THIS ORDER). Do NOT wrap the include in raw tags, which stops Liquid running it: {% include codetabs.html labels="Before|After" %} ```python # Class hierarchy ``` ```python # Idiomatic ``` The labels parameter is required: there is no default pair. Each label names one tab, for example "Before|After" or "Protocol|Callable". When labels is missing or blank the include renders nothing, and scripts/validate.py reports the page. Selecting a tab syncs every group on the page and is remembered across pages. {%- endcomment -%} {%- if include.labels != blank -%}
